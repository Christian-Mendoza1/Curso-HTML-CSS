# Curso de HTML y CSS Desde Cero a Avanzado

## Resumen de lo que aprenderemos

Aprenderemos las bases de la semántica de HTML, **para que sirve, su utilad, la sintaxis y metodologías**. Para pasar despues con el contenido de CSS, donde explicaremos la **sintaxis, valores, propiedades, valores, metodologías, utilización de variables, animaciones, flujo de cajas, Flexbox y Display Grid**.

En este repositorio encontrarás dos carpetas designadas una para **HTML y la otra para CSS**. Recomiendo que sigas el flujo de este repositorio empezando por aprender HTML y después pasar a la carpeta de CSS.
