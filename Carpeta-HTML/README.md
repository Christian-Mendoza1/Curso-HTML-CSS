# Curso HTML desde cero a avanzado

## ¿Qué es HTML? 

HTML significa **Hyper Text Markup Language** ó **Lenguaje de etiquetas de hipertexto**, que es el bloque de la construcción de las páginas web, **define la estructura y significado de la web**. 

Donde está es la parte escencial para crear una página web, ya que es la base (maqueteado web) donde se le da la forma que llevará nuestra web.
